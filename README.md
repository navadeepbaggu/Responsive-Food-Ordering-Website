
# Responsive Food Ordering Website

## Lab Experiment 3 – M2

A responsive restaurant discovery and food ordering website developed using HTML5 and CSS3.

## Features
- Responsive navigation using CSS Flexbox.
- Six restaurant cards using CSS Grid.
- Mobile-first responsive design.
- Media queries for mobile, tablet and desktop.
- Container queries.
- Restaurant card hover effects.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Container Queries

## Responsive Testing
Tested using Chrome DevTools:
- Mobile
- Tablet
- Desktop
